# Organize Orbit App

Build a modern, responsive Study Planner web application with a premium UI/UX using HTML, CSS, JavaScript (or React if Lovable's default stack requires it). The application should look polished enough for a hackathon demo and be fully functional.

## Project Name
Study Planner

## Goal
Help students organize their daily study tasks, track progress, and stay productive.

## Core Features

### Dashboard
- Welcome heading
- Current date and time
- Motivational study quote that changes on refresh

### Task Management
- Add new study tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Assign priority (High, Medium, Low)
- Select subject/category (Programming, Mathematics, Science, English, etc.)
- Optional due date
- Display task creation time

### Search & Filter
- Search tasks by keyword
- Filter by:
  - Completed
  - Pending
  - Priority
  - Subject

### Progress Tracking
- Progress bar
- Total tasks
- Completed tasks
- Pending tasks
- Completion percentage

### Productivity
- Daily study goal
- Streak counter (based on completing tasks)
- Celebrate reaching 100% completion with a simple animation

### Dark Mode
- Toggle between light and dark mode
- Save the user's preference

### Local Storage
- Persist all tasks after page refresh
- Persist theme preference

## UI/UX Requirements

Design a clean, modern productivity application with:
- Glassmorphism cards
- Gradient background
- Rounded corners
- Soft shadows
- Smooth animations and transitions
- Responsive design for desktop, tablet, and mobile
- Professional typography
- Modern icon set
- Attractive color palette
- Accessible layout

## Navigation
Single-page application with clearly separated sections:
- Dashboard
- Tasks
- Statistics

## Technical Requirements
- Clean, well-structured code
- Reusable components (if React is used)
- Clear comments where appropriate
- Fast loading
- Responsive across all screen sizes

## Bonus Features
- Export tasks as PDF
- Export tasks as CSV
- Keyboard shortcuts
- Drag-and-drop task reordering
- Pomodoro timer (25/5)
- Notes section for each task
- Notifications/reminders (where supported)

## Deliverables
- Fully functional application
- Clean project structure
- Professional UI suitable for a hackathon presentation
- No placeholder content
- Include sample tasks so the app looks complete on first launch

The final application should feel like a premium productivity tool rather than a basic to-do list.
